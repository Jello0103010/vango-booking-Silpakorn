# VanGo Booking | รถตู้หน้า ม.ศิลปากร

เว็บไซต์จำลองสำหรับโครงงานเดี่ยว HTML + CSS + JavaScript ไม่ใช้ฐานข้อมูลหรือ API

## ฟังก์ชัน
- 3 หน้า: `index.html` หน้าแรก/ตารางเดินรถ, `booking.html` จองรถ, `history.html` ประวัติ
- ต้นทาง: บริเวณมหาวิทยาลัยศิลปากร วิทยาเขตพระราชวังสนามจันทร์ จังหวัดนครปฐม
- ปลายทาง: รังสิต, สายใต้–ปิ่นเกล้า, กาญจนบุรี
- ราคา **จำลอง** 120, 100, 150 บาทตามลำดับ และเวลาเดินรถ **จำลอง** ตามที่แสดงในเว็บ
- จองวันนี้ถึง 7 วันข้างหน้า, ไม่รับจองรอบที่ผ่านไปแล้ว
- สุ่มความจุ 13 หรือ 19 ที่นั่งครั้งเดียวต่อเส้นทาง/วัน/เวลา เก็บไว้ใน localStorage
- ตรวจสอบที่นั่งว่าง, กรอกชื่อและเบอร์ผู้จอง, ยืนยันการจองทันที
- ค้นหาประวัติด้วยเบอร์โทรศัพท์, ดาวน์โหลดใบยืนยัน HTML หรือพิมพ์เป็น PDF

## วิธีใช้งานในเครื่อง
เปิด `index.html` ใน Chrome/Edge หรือเปิดด้วย VS Code Live Server

## เผยแพร่ผ่าน GitHub Pages
1. สร้าง Public repository ชื่อ `vango-booking`
2. อัปโหลดไฟล์ **ข้างในโฟลเดอร์นี้ทั้งหมด** ไปไว้ที่ root ของ repository (ต้องเห็น `index.html` ทันที)
3. เข้า Settings > Pages > Build and deployment > Deploy from a branch
4. เลือก branch `main`, folder `/(root)` แล้ว Save
5. รอให้ GitHub แสดงลิงก์ `https://USERNAME.github.io/vango-booking/`
6. เปิดลิงก์บนมือถือแล้วค่อยนำ URL จริงไปสร้าง QR Code

## ข้อจำกัดสำคัญ
- เป็นระบบจำลอง **ไม่ใช่ระบบขายตั๋วจริง** ราคา เวลา และจำนวนรถไม่ใช่ข้อมูลผู้ประกอบการที่ยืนยัน
- localStorage เก็บแยกตามเบราว์เซอร์/อุปกรณ์ ไม่สามารถแชร์ที่นั่งหรือประวัติระหว่างหลายเครื่อง
- ไม่มี Backend, API, การรับชำระเงินจริง หรือระบบรักษาความปลอดภัยระดับงานจริง
- ไม่ควรกรอกข้อมูลส่วนบุคคลจริงในการสาธิตสาธารณะ
