# เช็กลิสต์ทดสอบก่อนส่ง
- [ ] เปิดหน้าแรก ตารางเวลา และเลือกเส้นทางทั้ง 3 สาย
- [ ] จองรอบอนาคต 1 คนได้ และมีหมายเลขจอง
- [ ] จองหลายคนแล้วค่าโดยสารรวมถูกต้อง
- [ ] กลับหน้าแรกแล้วที่นั่งว่างของรอบเดิมลดลง
- [ ] รีเฟรชแล้วความจุรถไม่เปลี่ยน
- [ ] จองเกินที่นั่งว่างไม่ได้
- [ ] ค้นหาด้วยเบอร์โทรที่ใช้จองพบประวัติ
- [ ] ดาวน์โหลดใบยืนยัน และพิมพ์ PDF ได้
- [ ] เปิดเว็บจาก GitHub Pages บนมือถือได้
- [ ] QR Code ใช้ URL GitHub Pages จริง ไม่ใช่ URL ตัวอย่าง

หมายเหตุ: การทดสอบในเครื่องไม่เท่ากับการทดสอบหลังเผยแพร่ ต้องตรวจอีกครั้งหลังอัปโหลด
